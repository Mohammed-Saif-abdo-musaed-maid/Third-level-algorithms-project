# 📊 مشروع الخوارزميات العملي

تطبيق تعليمي تفاعلي مكتوب بلغة **Python** باستخدام مكتبة **Tkinter**، يهدف إلى توضيح طريقة عمل مجموعة من الخوارزميات من خلال محاكاة مرئية وتفاعلية.

يوفر البرنامج واجهة رسومية تسمح للمستخدم بإدخال مصفوفات من الأرقام، اختيار الخوارزمية، تشغيل عملية المحاكاة خطوة بخطوة، التحكم في سرعة التنفيذ، وإظهار تقرير نهائي عن عملية التنفيذ.

---

## 🎯 أهداف المشروع

يهدف المشروع إلى:

* تقديم الخوارزميات بطريقة مرئية وتفاعلية.
* مساعدة الطلاب على فهم آلية عمل خوارزميات الفرز.
* توضيح مفهوم التعقيد الزمني والمكاني للخوارزميات.
* عرض المقارنات والتبديلات أثناء عملية الفرز.
* توفير واجهة سهلة للتجربة باستخدام بيانات مختلفة.
* قياس الزمن المستغرق في تنفيذ الخوارزمية.
* تقديم تقرير نهائي يوضح نتائج عملية المحاكاة.

---

## 🚀 الخوارزميات المتوفرة

يحتوي التطبيق على الخوارزميات التالية:

1. **Merge Sort — خوارزمية الدمج**
2. **Bubble Sort — خوارزمية الفقاعية**
3. **Fibonacci — خوارزمية فيبوناتشي**
4. **Heap Sort — خوارزمية فرز الكومة**
5. **Insertion Sort — خوارزمية الحشر**
6. **Quick Sort — خوارزمية الفرز السريع**

يتم عرض هذه الخوارزميات ضمن قائمة رئيسية يستطيع المستخدم من خلالها اختيار الخوارزمية المطلوبة.

---

## 🖥️ واجهة البرنامج

يتكون التطبيق بشكل رئيسي من عدة شاشات:

### 1. شاشة تسجيل الدخول

تحتوي على:

* اسم المستخدم.
* كلمة المرور.
* تأكيد كلمة المرور.
* سؤال تحقق حسابي بسيط.
* زر تسجيل الدخول.
* زر الخروج.
* معلومات أعضاء الفريق والمشرف.

بعد نجاح عملية التحقق ينتقل المستخدم إلى قائمة الخوارزميات.

---

### 2. قائمة الخوارزميات

تظهر للمستخدم قائمة بالخوارزميات المتاحة، ويمكن اختيار أي خوارزمية للانتقال إلى شاشة المحاكاة الخاصة بها.

---

### 3. شاشة محاكاة الخوارزمية

تحتوي شاشة كل خوارزمية على:

* حقل إدخال المصفوفة.
* زر توليد أرقام عشوائية.
* زر تحميل وتأكيد المصفوفة.
* زر بدء المحاكاة.
* زر الإيقاف المؤقت والاستئناف.
* زر إعادة التعيين.
* زر مسح العناصر.
* زر عرض التقرير النهائي.
* شريط للتحكم في سرعة المحاكاة.
* مساحة رسومية لعرض المصفوفة.
* مساحة لعرض كود الخوارزمية وتحليل التعقيد.

تستخدم الواجهة `Canvas` لتمثيل عناصر المصفوفة على شكل أعمدة، مع تغيير ألوان العناصر أثناء المقارنة والتبديل.

---

## 🧮 طريقة إدخال البيانات

بالنسبة لخوارزميات الفرز، يتم إدخال الأرقام في حقل المصفوفة بحيث تكون الأرقام مفصولة بفواصل.

### مثال:

```text
3,1,4,1,5
```

أو:

```text
10,4,8,1,7,2,9,5,3,6
```

يقوم البرنامج بتحويل القيم المدخلة إلى قائمة من الأعداد الصحيحة قبل بدء المحاكاة.

كما يمكن استخدام زر **توليد أرقام عشوائية** لإنشاء مصفوفة عشوائية للتجربة.

---

## 🎨 المحاكاة المرئية

أثناء تشغيل الخوارزمية يتم تمثيل المصفوفة بصريًا على شكل أعمدة.

يتم تمييز العناصر التي تتم معالجتها بألوان مختلفة حسب مرحلة الخوارزمية، مما يساعد على متابعة خطوات التنفيذ وفهم طريقة عمل الخوارزمية.

كما يمكن للمستخدم التحكم في سرعة المحاكاة باستخدام شريط السرعة.

---

## 📈 تحليل الخوارزميات

### Bubble Sort

| الحالة          | التعقيد |
| --------------- | ------- |
| أفضل حالة       | O(n)    |
| متوسط الحالة    | O(n²)   |
| أسوأ حالة       | O(n²)   |
| التعقيد المكاني | O(1)    |

تعتمد الخوارزمية على مقارنة العناصر المتجاورة وتبديلها عندما تكون في ترتيب خاطئ.

---

### Merge Sort

| الحالة          | التعقيد    |
| --------------- | ---------- |
| أفضل حالة       | O(n log n) |
| متوسط الحالة    | O(n log n) |
| أسوأ حالة       | O(n log n) |
| التعقيد المكاني | O(n)       |

تعتمد على مبدأ **Divide and Conquer**، حيث يتم تقسيم المصفوفة إلى أجزاء أصغر ثم دمج الأجزاء بعد ترتيبها.

---

### Insertion Sort

| الحالة          | التعقيد |
| --------------- | ------- |
| أفضل حالة       | O(n)    |
| متوسط الحالة    | O(n²)   |
| أسوأ حالة       | O(n²)   |
| التعقيد المكاني | O(1)    |

تقوم الخوارزمية ببناء الجزء المرتب من المصفوفة عنصرًا بعد عنصر.

---

### Heap Sort

| الحالة          | التعقيد    |
| --------------- | ---------- |
| أفضل حالة       | O(n log n) |
| متوسط الحالة    | O(n log n) |
| أسوأ حالة       | O(n log n) |
| التعقيد المكاني | O(1)       |

تعتمد على بناء **Max Heap** ثم استخراج أكبر عنصر ووضعه في نهاية المصفوفة.

---

### Quick Sort

| الحالة          | التعقيد    |
| --------------- | ---------- |
| أفضل حالة       | O(n log n) |
| متوسط الحالة    | O(n log n) |
| أسوأ حالة       | O(n²)      |
| التعقيد المكاني | O(log n)   |

تعتمد على اختيار عنصر محوري **Pivot** وتقسيم المصفوفة إلى أجزاء ثم تطبيق الخوارزمية بشكل متكرر.

---

### Fibonacci

تستخدم شاشة خاصة لإدخال قيمة `N` وتوليد سلسلة فيبوناتشي، بدلًا من إدخال مصفوفة مثل خوارزميات الفرز.

## 📋 التقرير النهائي

بعد انتهاء المحاكاة يستطيع المستخدم اختيار **عرض التقرير النهائي**.

يعرض التقرير، بحسب الخوارزمية:

* اسم الخوارزمية.
* المصفوفة الأصلية.
* النتيجة بعد التنفيذ.
* الزمن المستغرق.
* عدد المقارنات.
* عدد التبديلات أو التحويلات.
* التعقيد الزمني.
* التعقيد المكاني.

يتم تخصيص التقرير لكل خوارزمية وفق البيانات التي يتم قياسها أثناء التنفيذ.

## ⏯️ التحكم بالمحاكاة

يوفر المشروع عدة خيارات للتحكم في التنفيذ:

### Start

بدء تشغيل الخوارزمية.

### Pause / Resume

إيقاف المحاكاة مؤقتًا أو استئنافها.

### Reset

إعادة المصفوفة إلى حالتها الأصلية وإيقاف المحاكاة الحالية.

### Clear

مسح البيانات والمصفوفة المعروضة.

### Speed

تغيير سرعة المحاكاة باستخدام شريط التحكم.

هذه الوظائف تعتمد على آلية الأحداث والخيوط `threading` المستخدمة لتشغيل المحاكاة دون تجميد الواجهة.
